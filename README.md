# 🐍 Snake Game – Java

A classic Snake Game developed using Java. The player controls a snake, collects food, increases their score, and avoids colliding with walls or its own body.

## 📌 Project Overview

This project is a Java-based desktop gaming application created as a 3rd Semester Java Microproject. It demonstrates Java programming concepts, GUI development, event handling, and game logic.

## ✨ Features

- Classic Snake gameplay
- Keyboard controls
- Food generation
- Score tracking
- Snake movement and growth
- Collision detection
- Game over functionality

## 🛠️ Technologies Used

- **Programming Language:** Java
- **GUI:** Java Swing
- **Libraries:** AWT and Swing
- **IDE:** Visual Studio Code
- **Version Control:** Git and GitHub

## 🚀 How to Run

### Method 1: Run using JAR file

1. Download or clone this repository.
2. Open the project folder in the terminal.
3. Execute:

```bash
java -jar SnakeGame.jar
```

### Method 2: Run using Java source code

1. Open the `src` folder.
2. Locate the main Java class.
3. Compile the source files according to their package structure.
4. Run the main class.

## 🎮 How to Play

- Use the arrow keys to control the snake.
- Eat the food to increase your score.
- Avoid hitting the walls.
- Avoid colliding with the snake's own body.
- Try to achieve the highest score!
